# To-Do List Application

A feature-rich To-Do List application built with Node.js, Express, and MongoDB.

## Features

- Create, edit, and delete tasks
- Mark tasks as complete/incomplete
- Categorize tasks (Work, Personal, Shopping, Health, Other)
- Set task priorities (Low, Medium, High)
- Add due dates to tasks
- Filter tasks by category and priority
- Modern and responsive UI

## Technologies Used

- Node.js
- Express.js
- MongoDB
- HTML5
- CSS3
- JavaScript (ES6+)

## Prerequisites

- Node.js (v12 or higher)
- MongoDB (running locally or a MongoDB Atlas account)

## Installation

1. Clone the repository:
```bash
git clone <your-repository-url>
cd todo-list
```

2. Install dependencies:
```bash
npm install
```

3. Start MongoDB:
Make sure MongoDB is running on your system.

4. Start the application:
```bash
node server.js
```

5. Open your browser and navigate to:
```
http://localhost:3000
```

## Usage

1. Add a new task:
   - Enter task description
   - Select category
   - Choose priority
   - Set due date (optional)
   - Click "Add Task"

2. Edit a task:
   - Click the "Edit" button
   - Modify task details in the modal
   - Click "Save Changes"

3. Complete a task:
   - Click the checkbox next to the task

4. Delete a task:
   - Click the "Delete" button

5. Filter tasks:
   - Use the category and priority filters at the top
